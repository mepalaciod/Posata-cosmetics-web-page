# POSATA COSMETICS 

![Logo](Logo.png)

Posata es una página web donde las personas pueden realizarsus  compras de todos los productos y sus diferentes marcas, marcas de cosméticos, productos para *uñas* y el *Cabello* como: Ani-k, Bloomshell, La Poción, Milagros y Ritual botánico. 

Este sitio web se desarolla con la finalidad de que sea un catálogo y funcionará como ecommerce.

## Tecnologías: 
- Bootstrap
- React
